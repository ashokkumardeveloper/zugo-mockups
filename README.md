# Zugo app mockups

Clickable HTML mockups of the Zugo food-delivery apps. Plain HTML, CSS and JavaScript, no build step.

| Page | What it is |
|---|---|
| `zugo-app.html` | Customer app "Zugo", full screen for phone browsers |
| `zugo-admin.html` | Admin app "Zugo Operator", full screen for phone browsers |
| `index.html` | Desktop lab view: phone frame, screen list, notes, flows and project plan |

Open any file directly in a browser, or visit the GitHub Pages site for this repo.

Sample data only. Names, phone numbers and orders are made up.
